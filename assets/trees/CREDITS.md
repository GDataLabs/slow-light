# Pine trees

Adapted from [Pine Sapling Medium](https://polyhaven.com/a/pine_sapling_medium)
by Rico Cilliers (modeling) and Rob Tuytel (photography), licensed
[CC0](https://polyhaven.com/license).

Three tree variants retain original bark/branch texture maps. Geometry was
simplified for the lakeside viewing distance using meshoptimizer 1.2.0.
The shipped geometry is 38,517 triangles across all three variants (1.16 MB),
compared with the source's 263 MB geometry buffer. Original texture files remain
unchanged. Reproduce with `scripts/prepare-pines.mjs` and the original 1K glTF
bundle. Full source geometry is not shipped with the app.
